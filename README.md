# Лабораторна робота №1: Фронтенд веб-застосунку "Трекер інцидентів кібербезпеки" (Варіант 2)

Реалізовано клієнтську частину (фронтенд) трекера інцидентів кібербезпеки без використання фреймворків (чистий HTML, CSS та JavaScript).

## Опис проєкту

Веб-застосунок дозволяє реєструвати, редагувати та відстежувати інциденти кібербезпеки.

### Основні функції:

1. **Додавання інцидентів**: форма з 5 обов'язковими полями (Дата, Тип, Рівень загрози, Репортер, Коментарі).
2. **Локальна валідація**:
   - Поля підсвічуються червоним кольором при некоректному введенні.
   - Детальні помилки виводяться безпосередньо під кожним полем.
3. **Редагування та видалення**:
   - Можливість видалити будь-який інцидент з таблиці.
   - Можливість редагувати інцидент: при натисканні "Редагувати" форма заповнюється даними інциденту, переходить у жовтий режим редагування, а кнопка змінюється на "Зберегти зміни".
4. **Пошук, фільтрація та сортування**:
   - Пошук за призвищем/ім'ям репортера.
   - Фільтрація інцидентів за типом загрози.
   - Сортування за датою (від новіших до старіших або навпаки).
5. **Збереження даних**: всі інциденти зберігаються у локальному сховищі браузера (`localStorage`), тому вони не зникають при повторному відкритті сторінки.
6. **Дизайн**: Інтерфейс розділений на дві колонки (форма зліва, таблиця справа).

## Як запустити проєкт

Зайдіть у папку `frontend` та відкрийте файл `index.html` у будь-якому веб-браузері.
