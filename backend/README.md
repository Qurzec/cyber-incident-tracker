# Документація та інструкція для Backend API (Лабораторна робота №2)

Цей проект є бекенд-частиною для трекера інцидентів кібербезпеки з інтегрованим списком користувачів системи.

---

## Як запустити проект локально

Усі команди запускаються з папки `backend`:

1. **Встановлення залежностей** (інсталює `express` та `nodemon`):
   ```bash
   npm install
   ```

2. **Запуск у режимі розробки** (сервер автоматично перезапускається після зміни коду):
   ```bash
   npm run dev
   ```

3. **Запуск у звичайному режимі** (production-старт):
   ```bash
   npm start
   ```

Сервер за замовчуванням запускається на порту **3000** за адресою: `http://localhost:3000`.

---

## Реалізовані сутності (Entities)

### 1. Користувачі (Users)
Зберігають дані про зареєстрованих у системі користувачів.
Поля:
- `id` (генерується сервером) — унікальний ідентифікатор.
- `username` (рядок, обов'язкове, від 3 символів) — нікнейм користувача.
- `email` (рядок, обов'язкове, дозволено лише поштові адреси домену `knu.ua`) — електронна пошта.
- `password` (рядок, обов'язкове, від 6 символів) — пароль користувача.
- `role` (рядок, обов'язкове, одне з: Admin, User, Editor) — роль.

*З метою безпеки паролі користувачів не повертаються в API відповідях.*

### 2. Інциденти (Incidents)
Зберігають записи про інциденти кібербезпеки.
Поля:
- `id` (генерується сервером) — унікальний ідентифікатор.
- `date` (рядок, обов'язкове) — дата та час події.
- `tag` (рядок, обов'язкове, одне з: DDoS-атака, Фішинг, Вірусне ПЗ, Злам акаунту, Інше) — тип інциденту.
- `severity` (рядок, обов'язкове, одне з: Низький, Середній, Високий, Критичний) — рівень загрози.
- `reporter` (рядок, обов'язкове, 3-50 символів) — хто повідомив про подію.
- `comments` (рядок, необов'язкове, від 5 символів якщо вказано) — деталі інциденту.

## Приклади запитів (curl-команди для перевірки)

Ви можете виконувати ці команди у своєму терміналі для перевірки:

### Робота з користувачами (Users API):

* **Отримати всіх користувачів (GET):**
  ```bash
  curl -i http://localhost:3000/api/users
  ```

* **Отримати конкретного користувача за ID (GET):**
  ```bash
  curl -i http://localhost:3000/api/users/1717500000001
  ```

* **Створити нового користувача (POST):**
  ```bash
  curl -i -X POST http://localhost:3000/api/users \
    -H "Content-Type: application/json" \
    -d '{"username": "ivan_cyber", "email": "ivan@knu.ua", "password": "secure123", "role": "User"}'
  ```

* **Оновити дані користувача (PUT):**
  ```bash
  curl -i -X PUT http://localhost:3000/api/users/1717500000002 \
    -H "Content-Type: application/json" \
    -d '{"username": "olena_admin", "email": "olena@knu.ua", "password": "newpassword123", "role": "Admin"}'
  ```

* **Видалити користувача за ID (DELETE):**
  ```bash
  curl -i -X DELETE http://localhost:3000/api/users/1717500000001
  ```

* **Тест помилки валідації (POST з некоректними даними / без домену knu.ua):**
  ```bash
  curl -i -X POST http://localhost:3000/api/users \
    -H "Content-Type: application/json" \
    -d '{"username": "iv", "email": "invalid-email@gmail.com", "password": "123", "role": "invalid_role"}'
  ```

### Робота з інцидентами (Incidents API):

* **Отримати всі інциденти (GET):**
  ```bash
  curl -i http://localhost:3000/api/incidents
  ```

* **Отримати інцидент за ID (GET):**
  ```bash
  curl -i http://localhost:3000/api/incidents/1717500000020
  ```

* **Створити новий інцидент (POST):**
  ```bash
  curl -i -X POST http://localhost:3000/api/incidents \
    -H "Content-Type: application/json" \
    -d '{"date": "2026-06-04T12:00", "tag": "Вірусне ПЗ", "severity": "Критичний", "reporter": "Антивірусний центр", "comments": "Виявлено шифрувальник на робочій станції бухгалтера."}'
  ```

* **Оновити дані інциденту (PUT):**
  ```bash
  curl -i -X PUT http://localhost:3000/api/incidents/1717500000020 \
    -H "Content-Type: application/json" \
    -d '{"date": "2026-06-04T10:00", "tag": "DDoS-атака", "severity": "Критичний", "reporter": "Адміністратор мережі", "comments": "Потужність атаки перевищила 10 Gbps, сервіси недоступні."}'
  ```

* **Видалити інцидент за ID (DELETE):**
  ```bash
  curl -i -X DELETE http://localhost:3000/api/incidents/1717500000021
  ```

* **Тест помилки 404 при неіснуючому ID:**
  ```bash
  curl -i http://localhost:3000/api/incidents/9999999999
  ```
