# Документація та інструкція для Backend API (Лабораторна робота №2 - Рівень "На Відмінно")

Цей проект є бекенд-частиною для трекера інцидентів кібербезпеки з інтегрованим списком користувачів системи. Проект переписано на **TypeScript** із використанням чистої трирівневої архітектури (роути/контролери -> сервіси -> репозиторії).

---

## Як запустити проект локально

Усі команди запускаються з папки `backend`:

1. **Встановлення залежностей**:

   ```bash
   npm install
   ```

2. **Запуск у режимі розробки** (автоматичне відслідковування змін через `tsx watch`):

   ```bash
   npm run dev
   ```

3. **Компіляція проекту** (компілює TypeScript у JavaScript у папку `dist`):

   ```bash
   npm run build
   ```

4. **Запуск скомпільованої версії** (production-старт):

   ```bash
   npm start
   ```

5. **Перевірка стилю коду та форматування**:
   ```bash
   npm run lint
   npm run format
   ```

Сервер за замовчуванням запускається на порту **3000** за адресою: `http://localhost:3000`.

## Реалізовані сутності (Entities)

### 1. Користувачі (Users)

- `id` (генерується сервером) — унікальний ідентифікатор.
- `username` (рядок, обов'язкове, від 3 символів) — нікнейм користувача.
- `email` (рядок, обов'язкове, дозволено лише поштові адреси домену `knu.ua`) — електронна пошта.
- `password` (рядок, обов'язкове, від 6 символів) — пароль користувача.
- `role` (рядок, обов'язкове, одне з: Admin, User, Editor) — роль.

_З метою безпеки паролі користувачів не повертаються в API відповідях._

### 2. Інциденти (Incidents)

- `id` (генерується сервером) — унікальний ідентифікатор.
- `date` (рядок, обов'язкове) — дата та час події.
- `tag` (рядок, обов'язкове, одне з: DDoS, Фішинг, Вредоносне ПО, Несанкціонований доступ, Інше) — тип інциденту.
- `severity` (рядок, обов'язкове, одне з: Низький, Середній, Високий, Критичний) — рівень загрози.
- `reporter` (рядок, обов'язкове, 3-50 символів) — хто повідомив про подію.
- `comments` (рядок, необов'язкове, від 5 символів якщо вказано) — деталі інциденту.

## Додаткові REST-можливості (Рівень "На Відмінно")

### 1. Фільтрація списку інцидентів (Query-параметри `tag` та `severity`)

- Дозволяє відфільтрувати список. Наприклад, отримати лише інциденти з рівнем "Високий":
  ```bash
  curl -i "http://localhost:3000/api/incidents?severity=Високий"
  ```

### 2. Сортування (Query-параметри `sortBy` та `sortDir`)

- Дозволяє сортувати за будь-яким полем інциденту (наприклад, `date` або `reporter`) у напрямках `asc` або `desc`:
  ```bash
  curl -i "http://localhost:3000/api/incidents?sortBy=date&sortDir=desc"
  ```

### 3. Пагінація (Query-параметри `page` та `pageSize`)

- Обмежує кількість повернутих записів для сторінки:
  ```bash
  curl -i "http://localhost:3000/api/incidents?page=1&pageSize=1"
  ```
- _Усі запити списків повертають стандартизований формат: `{ items: [...], total: N }`._

### 4. Часткове оновлення записів (метод `PATCH`)

- Дозволяє оновити лише окремі поля сутності без необхідності надсилати весь об'єкт.

## Приклади запитів (curl-команди для перевірки)

### Робота з користувачами (Users API):

- **Отримати всіх користувачів (GET):**

  ```bash
  curl -i http://localhost:3000/api/users
  ```

- **Отримати конкретного користувача за ID (GET):**

  ```bash
  curl -i http://localhost:3000/api/users/1717500000001
  ```

- **Створити нового користувача (POST):**

  ```bash
  curl -i -X POST http://localhost:3000/api/users \
    -H "Content-Type: application/json" \
    -d '{"username": "ivan_cyber", "email": "ivan@knu.ua", "password": "secure123", "role": "User"}'
  ```

- **Частково оновити користувача (PATCH):**

  ```bash
  curl -i -X PATCH http://localhost:3000/api/users/1717500000002 \
    -H "Content-Type: application/json" \
    -d '{"role": "Admin"}'
  ```

- **Видалити користувача за ID (DELETE):**
  ```bash
  curl -i -X DELETE http://localhost:3000/api/users/1717500000001
  ```

### Робота з інцидентами (Incidents API):

- **Отримати всі інциденти (GET):**

  ```bash
  curl -i http://localhost:3000/api/incidents
  ```

- **Створити новий інцидент (POST):**

  ```bash
  curl -i -X POST http://localhost:3000/api/incidents \
    -H "Content-Type: application/json" \
    -d '{"date": "2026-06-04T12:00", "tag": "Вредоносне ПО", "severity": "Критичний", "reporter": "Ivan Ivanov", "comments": "Виявлено шифрувальник на робочому компютері."}'
  ```

- **Частково оновити коментар в інциденті (PATCH):**

  ```bash
  curl -i -X PATCH http://localhost:3000/api/incidents/1717500000020 \
    -H "Content-Type: application/json" \
    -d '{"comments": "Оновлені деталі: DDoS-атака припинилась."}'
  ```

- **Видалити інцидент за ID (DELETE):**
  ```bash
  curl -i -X DELETE http://localhost:3000/api/incidents/1717500000021
  ```
